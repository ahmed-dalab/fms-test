# fms-test

This project is a Fleet Management System (FMS) with a focus on truck management.

## Backend Features

The backend is built with Java and Spring Boot and provides a REST API for the following features:

*   **Authentication**: Secure user registration and login using JWT (JSON Web Tokens).
*   **User Management**: Basic user management functionalities.
*   **Truck Management**: Create, read, update, and delete trucks.
*   **Driver Management**: Manage driver information.
*   **Trip Management**: Track trips made by trucks.
*   **Expense Management**: Record and manage expenses related to trucks and trips.
*   **Fuel Record Management**: Keep track of fuel consumption.
*   **Maintenance Record Management**: Log and manage truck maintenance activities.

### Technologies Used

*   **Framework**: Spring Boot
*   **Language**: Java
*   **Database**: PostgreSQL
*   **Security**: Spring Security with JWT
*   **API Documentation**: Swagger/OpenAPI
*   **Build Tool**: Maven
